# Frontend

## Main

The core set for comprehensive frontend development. Each skill has a distinct responsibility: design, interaction
quality, React architecture, and technical auditing.

| Skill | Description |
| --- | --- |
| [`impeccable`](https://github.com/pbakaus/impeccable) | **Design and UX.** The primary tool for designing and improving interfaces. Covers visual direction, composition, typography, color, responsiveness, UX, accessibility, and final polish. |
| [`emil-design-eng`](https://github.com/emilkowalski/skills) | **Design Engineering.** The complete skill suite for implementation quality, micro-animations, transitions, interactivity, and visual precision. When installing this Main entry, install the entire suite from the linked repository, including `emil-design-eng`, `animate`, `review-animations`, `choreograph`, `break-ui`, and all other skill modules it provides. These modules are part of the core installation. |
| [`vercel-composition-patterns`](https://github.com/vercel-labs/agent-skills/tree/main/skills/composition-patterns) | **React architecture.** Helps build scalable, reusable components, apply Compound Components, organize state correctly, and avoid excessive boolean props. |
| [`react-doctor`](https://github.com/millionco/react-doctor) | **Quality assurance.** Automatically audits React applications for performance, security, correctness, accessibility, and architecture. Identifies issues, suggests fixes, and rates project health on a scale of 0–100. |

## Alternatives

Backup and specialized options. These do not need to be installed alongside the core set. Add them when needed or use
them as alternatives to the corresponding skills in Main.

| Skill | Description |
| --- | --- |
| [`frontend-design`](https://github.com/anthropics/skills/tree/main/skills/frontend-design) | **Anthropic Frontend Design.** Helps create distinctive interfaces with an original visual direction, thoughtful typography, and composition. An alternative to `impeccable`; its functionality substantially overlaps. |
| [`ui-ux-pro-max`](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | **UI/UX Pro Max.** A large library of design resources: UI styles, color palettes, font pairings, UX guidelines, and patterns for different technology stacks. Useful for quickly choosing a visual direction. An alternative to `impeccable`, rather than a required addition. |
| [`design-taste-frontend`](https://github.com/Leonxlnx/taste-skill) | **Taste Skill.** An anti-slop approach to design that helps create distinctive websites and landing pages instead of typical templated AI interfaces. It applies its own visual rules and fairly strict stylistic constraints, which may conflict with an existing design system. |
| [`unslop`](https://github.com/heydamir/unslop) | **Unslop.** Helps remove generic AI-generated design patterns, establish a distinct visual identity for a product, and make the interface more intentional. Overlaps with `impeccable` and `emil-design-eng`; useful as an additional tool for improving generic-looking UI. |
| [`web-design-guidelines`](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines) | **Vercel Web Design Guidelines.** Reviews interfaces against the Web Interface Guidelines, covering accessibility, HTML semantics, keyboard navigation, focus states, forms, animations, typography, and performance. An additional audit that partially overlaps with `impeccable` and `react-doctor`. |
