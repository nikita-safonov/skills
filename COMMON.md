# Common

The recommended core toolkit for everyday development: creating branches, committing changes, preparing merge requests,
and reviewing code.

| Skill | Description |
| --- | --- |
| [`git-commit`](./skills/git-commit/SKILL.md) | **Git commits.** Inspects staged, unstaged, and untracked changes, selects the intended files, and creates a commit with an accurate Conventional Commit message in English. Checks for sensitive files and unrelated changes before committing. |
| [`git-branch`](./skills/git-branch/SKILL.md) | **Git branches.** Creates a branch following repository naming conventions. Determines the base branch, validates the name, checks for conflicts and uncommitted changes, and verifies that the new branch is checked out. |
| [`git-merge-request`](./skills/git-merge-request/SKILL.md) | **Pull and merge requests.** Reviews commits and the actual diff, resolves the target branch from the repository workflow, and prepares an English title and description. Pushes the branch or creates the request only when authorized by the user's instructions. |
| [`code-review`](https://github.com/mattpocock/skills/blob/main/skills/engineering/code-review/SKILL.md) | **Code review.** Reviews changes against a chosen commit, branch, tag, or merge base along two axes: repository coding standards and the originating issue or specification. Runs independent reviews in parallel and reports their findings separately. |
